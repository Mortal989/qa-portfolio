# Portfólio QA

Portfólio de Quality Assurance (QA) com projetos práticos de testes de software, documentação e automação.

## Projetos

### 01 — Testes Manuais

Projeto com testes funcionais, documentação de casos de teste, registro de possíveis bugs e evidências.

**Status:** Concluído.

[ Acessar projeto ](01-testes-manuais/)

### 02 — Testes de API com Postman

Projeto para desenvolver conhecimentos em testes de API, validação de requisições e respostas HTTP.

**Status:** Planejado.

### 03 — Automação Web com Cypress + JavaScript

Projeto para praticar automação de testes web, validação de funcionalidades e execução de testes automatizados.

**Status:** Planejado.

### 04 — Automação Mobile com Robot Framework + Appium

Projeto para praticar automação de testes em aplicativos mobile, utilizando Robot Framework e Appium.

**Status:** Planejado.

## Objetivo

Desenvolver habilidades práticas em QA, abrangendo testes manuais, testes de API, automação web e automação mobile.
