# 01 - Testes Manuais

Projeto de testes manuais desenvolvido como parte do meu portfólio de QA (Quality Assurance).

## Objetivo

Documentar a execução de testes funcionais, a elaboração de casos de teste, a identificação de possíveis bugs e o registro de evidências.

## Aplicação testada

- **Sistema:** SauceDemo
- **URL:** https://www.saucedemo.com/
- **Tipo de teste:** Testes funcionais manuais

## Atividades realizadas

- Elaboração e execução de casos de teste.
- Validação de login com cenários positivos e negativos.
- Identificação e documentação de possíveis bugs.
- Registro e organização de evidências dos testes.

## Estrutura do projeto

- `casos-de-teste.md` — documentação dos casos de teste.
- `bugs-encontrados.md` — registro dos bugs identificados.
- `evidencias/` — imagens utilizadas como evidências dos testes.

## Status do projeto

- 3 casos de teste de login documentados e executados.
- 3 possíveis bugs registrados para análise.
