# Relatório Final — Testes Manuais

## 1. Objetivo

Registrar os resultados dos testes funcionais realizados na aplicação SauceDemo, documentando os cenários testados, as evidências e os possíveis bugs identificados.

## 2. Aplicação testada

- **Sistema:** SauceDemo
- **URL:** https://www.saucedemo.com/
- **Tipo de teste:** Testes funcionais manuais

## 3. Resumo dos testes

| ID | Cenário | Resultado |
|---|---|---|
| CT-001 | Login com credenciais válidas | Aprovado |
| CT-002 | Login com senha inválida | Aprovado |
| CT-003 | Login com campos vazios | Aprovado |

**Total:** 3 casos de teste executados.

## 4. Bugs identificados

Foram registrados 3 possíveis bugs relacionados à divergência entre as descrições e as imagens dos produtos:

- **BUG-001:** Divergência entre a descrição e a imagem da camiseta.
- **BUG-002:** Divergência na quantidade de botões do macacão infantil.
- **BUG-003:** Divergência na cor da camiseta.

Os registros estão disponíveis em `bugs-encontrados.md`, acompanhados das respectivas evidências.

## 5. Evidências

As imagens utilizadas para comprovar os resultados estão organizadas na pasta `evidencias/`.

## 6. Conclusão

Os testes permitiram validar os cenários de login documentados e identificar possíveis inconsistências nas informações visuais dos produtos.

Este projeto demonstra a aplicação de conceitos de testes funcionais manuais, documentação de casos de teste, registro de defeitos e organização de evidências.

**Observação:** Os possíveis bugs de produtos devem ser confirmados com base nos requisitos esperados da aplicação.
