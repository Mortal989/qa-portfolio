# Projeto 02 — Testes de API com Postman

## Objetivo
Desenvolver testes de API utilizando Postman e JavaScript para validar respostas HTTP e dados retornados pela API.

## Ferramentas utilizadas
- Postman
- JavaScript
- JSONPlaceholder (API pública para treinamento)

## Testes implementados
- Validação do nome do usuário.
- Validação do status HTTP 200.
- Validação do e-mail do usuário.

## Endpoint testado
`GET https://jsonplaceholder.typicode.com/users/1`

## Resultado
Os três testes foram executados com sucesso no Postman.

## Próximas etapas
- Adicionar a coleção exportada do Postman.
- Ampliar a cobertura dos testes.
- Documentar novos cenários de teste.
